# Collector Foil A+ Ticket Redesign

## Goal

결제 완료 화면의 실제 티켓을 얇은 목록형 카드가 아니라 공연 굿즈처럼 보이는 `Collector Foil A+` 패스로 재설계한다. 기존 5.2초 실시간 DOM 리빌과 실제 예매 데이터 계약은 유지한다.

## Visual Direction

- 데스크톱 실루엣은 `13 / 5` 비율로 조정해 기존 `1280 / 422`보다 덜 얇고 더 묵직하게 보이게 한다.
- 포스터 영역은 전체 너비의 약 27%를 사용하고, 포스터가 티켓 높이를 적극적으로 채우도록 한다.
- 바탕은 매트 블랙을 유지하되 인디고와 핑크의 낮은 채도 광원을 포스터 경계와 가장자리에 배치한다.
- 외곽에는 얇은 이리데슨트 포일 테두리를, 절취선에는 실제 티켓처럼 반원 노치를 둔다.
- 제목은 현재보다 크게, 주요 예매 정보는 3열 그리드로 명확하게 읽히게 한다.
- 스텁에는 실제 주문번호와 결제 시각, 장식용 정품 실(seal)만 표시한다.

## Data and Accessibility

- `BookingCompleteView`의 값만 표시한다.
- 존재하지 않는 좌석, 게이트, QR, 바코드, 입장 번호를 생성하지 않는다.
- 실제 티켓은 하나의 `article`로 유지한다.
- 리빌의 뒷면, 광택, 포일, 실, 절취 노치는 모두 접근성 트리에서 제외한다.
- 포스터 로드 실패 시 기존의 안정적인 대체 포스터를 유지한다.

## Responsive Behavior

- `64rem` 미만에서는 가로 티켓을 세로형 컬렉터 패스로 재배치한다.
- 포스터를 상단 비주얼로 올리고 본문과 스텁을 순서대로 쌓는다.
- 정보는 누락하지 않으며 작은 화면에서도 가로 스크롤을 만들지 않는다.
- 모바일과 `prefers-reduced-motion`에서는 기존 정책대로 시네마틱 리빌을 재생하지 않는다.

## Motion Integration

- 기존의 세로 진입, 약 30도 기울기, 느린 3D 회전, 안착, 단발 광택 타이밍은 변경하지 않는다.
- 리빌 뒷면과 잔상 프록시의 비율만 실제 티켓의 `13 / 5` 실루엣과 맞춘다.
- 티켓 컴포넌트 자체에는 반복 애니메이션을 추가하지 않는다. 최종 포일 반짝임은 기존 리빌 광택이 담당한다.

## Acceptance Criteria

- 티켓은 `data-ticket-layout="collector-foil-a-plus"`를 사용한다.
- CSS와 시네마틱 뒷면/잔상은 모두 `13 / 5` 비율을 공유한다.
- 데스크톱에는 확대된 포스터, 큰 제목, 포일 외곽선, 절취 노치, 정품 실이 보인다.
- 모바일은 세로형 패스이며 모든 실제 예매 정보를 유지한다.
- 티켓 단위 테스트, 리빌 단위 테스트, 결제 완료 통합 테스트가 통과한다.
