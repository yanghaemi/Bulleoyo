## 0. 결론 [권]

| 역할 | 현행 | 권고 |
|------|------|------|
| 주 네트워크 | Polygon Amoy | **Kaia Kairos** (chainId 1001) |
| 백업 | EC2 Besu 프라이빗 | EC2 Besu 프라이빗 (유지) |
| 제외 | — | Polygon Amoy, Ethereum Sepolia·L2 Sepolia, Hoodi |

바꾸는 이유 네 가지:

1. **Amoy의 운영 환경이 7월에 나빠졌다.** 공식 공개 RPC(`rpc-amoy.polygon.technology`)가 **2026-07-17 종료**됐고, 공식 faucet은 **중단**됐다. 남은 faucet은 메인넷 ETH 0.001 이상 보유·실거래 이력(Alchemy·Chainlink), 트윗 공유(QuickNode), 메인넷 0.08 ETH(Chainstack) 같은 조건이 붙는다. 메인넷 자산이 없는 학생 팀에게 가스 확보가 병목이 된다.
2. **Kairos는 faucet이 조건 없이 50 KAIA/일**이다. 로그인·메인넷 잔고·SNS 요건이 없다. 25 gkei 기준 가스로 계산하면 50 KAIA는 전송 9만 건 분량이라, 팀원 5명 하루 수령으로 배포·리허설·부하 테스트를 전부 덮는다.
3. **데모 UX가 좋다.** 블록 1초·PBFT 즉시 확정(리오그 없음). Amoy(2~3초 + finality 대기)보다 "예매 → 온체인 기록 확정" 표시가 빠르고 단순해진다.
4. **핀테크·원화 스테이블코인 서사와 맞는다.** Kaia는 카카오(클레이튼)·라인(핀시아) 통합 한국계 L1이고, 2026-05 "아시아 스테이블코인 허브·원화 스테이블코인 인프라" 노선을 공식화했다. **KB금융이 2026-05-17 Kaia 위에서 원화 스테이블코인 발행→결제→가맹점 정산→해외송금 전 단계 PoC를 완료**했고, JPYC(엔 스테이블코인)가 05-15 메인넷에 올라갔다. "은행이 원화 스테이블코인 정산을 검증한 체인의 테스트넷에서 KRWS 정산을 시연한다"는 한 줄이 생긴다.

기술 스택은 그대로 간다 — Kairos는 Prague(2025-07)·Osaka(2026-02) 하드포크까지 적용된 최신 EVM이라 **OpenZeppelin v5·Hardhat 3·web3j(`eth_` 네임스페이스) 변경 없음**. 단 두 가지를 알아야 한다: ① Hardhat 3의 KaiaScan 자동 검증은 아직 개발 중 → 웹 UI에서 수동 검증(컨트랙트 2종, 1회) ② legacy tx는 `gasPrice ≥ baseFee`(하한 25 gkei)가 강제되므로 web3j에서 `eth_gasPrice` 값을 그대로 쓴다.

### 2.4 Besu 프라이빗 (백업 유지)

faucet 불필요·완전 통제·리허설 안정성이 장점. 공개 익스플로러가 없어 "누구나 검증" 서사가 약해지고 Blockscout 자체 운영이 필요하다 → **주가 아닌 백업**. Kairos 장애 시 전환하도록 Hardhat 네트워크 2개(`kairos`, `besu`)와 컨트랙트 주소 환경변수를 처음부터 이중화한다.
