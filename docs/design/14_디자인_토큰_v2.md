# 디자인 토큰 v2 — 색·폰트·반경 정본

- 작성 2026-09-08(v1) · 개정 **2026-09-10(v2)** · 결정 **신현경(UI/UX)** · 정리 이강륜 · 상태: **확정**
- v2에서 v1 §6의 미결 세 건이 전부 닫혔다(포커스 색·primary hover·warning 사용 범위). 폰트는 v1 기준을 재확인했고 코드가 벗어난 두 곳을 되돌린다.
- 이 문서가 토큰 정본이다. `frontend/src/styles.css`의 `@theme` 블록이 이 표를 따르고, 기술 스택 v3 §3.1의 amber `@theme`는 이 문서로 대체됐다(§5).
- 목업 32개(`docs/design/mockup/`)는 amber 시안으로 **보존하고 고치지 않는다.** 화면설계 v6의 구조·흐름은 그대로이고 색만 이 문서를 따른다.

## 1. 결정 요약

### v2 (신현경, 2026-09-10)

- **Focus는 `#5B54FF`** — 브랜드 primary와 다른 별색이다. **2px 링 + 2px 오프셋**으로 쓰고 **컴포넌트 테두리 두께는 바꾸지 않는다**(선택 상태와 같은 원칙 — 두께가 바뀌면 행 높이가 흔들린다).
- **Primary hover도 `#5B54FF`** — 기본 primary는 `#3129DD` 유지. `--color-primary-bright`와 `--color-focus`는 **동일한 색상 값 `#5B54FF`를 공유하되**, hover와 포커스 링이라는 역할을 구분하기 위해 두 시맨틱 토큰을 각각 유지한다. v1 코드에 있던 `--color-primary-light #3a44e4`·`--color-primary-hover #1b1888` 두 값은 **삭제**한다.
- **Warning은 진행을 막지 않는 주의에만** — 마감 임박·확인 필요 등. **결제 불가·잔액 부족처럼 진행을 막는 것은 Warning이 아니라 Danger다.** 선택·포커스·일반 강조에는 쓰지 않는다.
- **폰트는 v1 기준 그대로 통일** — 영문 본문 DM Sans · 한글 본문 Noto Sans KR · **금액과 식별자(가격·예매번호·티켓번호)는 DM Mono**. 일반 날짜·수량 같은 숫자는 본문 폰트를 따른다. 따라서 코드의 `Inter`(숫자용)·`JetBrains Mono`(식별자용)는 정리 대상이다.

### v1 (신현경, 2026-09-08)

- 브랜드는 **blue 기반**(`#3129DD`). 기존 amber(`#E39B2B`)는 브랜드 색이 아니라 **Warning 전용**으로만 남긴다.
- 선택 상태는 **테두리 두께를 바꾸지 않고** Selected soft 배경 + Selected 텍스트·아이콘으로 표현한다(와이어프레임 수정 요청 §14 — 두께가 바뀌면 행 높이가 흔들린다). 기존 후보 `#2596BE`는 다른 색과 조화가 애매해 `#D9468D`로 변경.
- 폰트는 **DM Sans 유지 + Noto Sans KR 폴백 필수**(DM Sans에 한글 글리프가 없어 폴백이 없으면 OS별 system-ui로 갈라진다). 모노는 DM Mono.

## 2. 토큰 표

Tailwind v4는 `--color-*`·`--font-*`·`--radius-*`·`--breakpoint-*` 네임스페이스만 유틸리티로 만든다. **역할 이름만 쓰고 팔레트 이름(`blue-500`)은 쓰지 않는다**(스택 v3 §3.1 규칙 유지).

### 2.2 폰트

```css
--font-sans: "DM Sans", "Noto Sans KR", system-ui, sans-serif;
--font-mono: "DM Mono", ui-monospace, monospace;
```

- 두 벌 모두 `frontend/index.html`에서 Google Fonts(css2)로 명시 로드한다. Noto Sans KR은 용량이 커 unicode-range 분할 서빙에 의존한다.
- **[v2] 어디에 무엇을 쓰는가** — 영문 본문 DM Sans · 한글 본문 Noto Sans KR(폴백으로 자동) · **금액과 식별자는 DM Mono**(가격·예매번호·티켓번호·주소·tx 해시). **일반 날짜·수량 같은 숫자는 본문 폰트**를 따른다.
- **[v2] 코드 정리 대상** — `--font-num: Inter`(금액용 별도 폰트)와 `--font-mono`의 `JetBrains Mono` 선순위는 이 기준에서 벗어난다. `--font-num`을 없애고 금액을 `--font-mono`(DM Mono)로 되돌린다. `frontend/index.html`의 Google Fonts 요청에서도 두 벌을 뺀다.
- `Inter`·`Montserrat`는 실험 테마(`theme-apple.css`·`theme-meta.css`) 전용이며 팀 토큰이 아니다.

## 3. 규칙

1. 컴포넌트는 값을 직접 쓰지 않고 토큰 유틸리티(`bg-primary`·`text-sel`·`rounded-card`)만 쓴다. 테마 교체는 `@theme` 블록만 바꾼다.
2. 선택 상태에 Outline·Stroke·두께 변화를 쓰지 않는다. `bg-sel-soft` + `text-sel`.
3. 키보드 포커스 링은 유지한다(`focus-visible`). 접근성 최소 요건(UX-02 터치 44px과 함께).
4. amber(`--color-warning`)를 버튼·링크·브랜드 요소에 쓰지 않는다.
5. 프레스 `scale(.97)` 160ms `cubic-bezier(.23,1,.32,1)`, 호버는 `(hover:hover) and (pointer:fine)` 게이트, `prefers-reduced-motion` 존중 — 스택 v3 §3.1의 모션 규칙 그대로.
6. 실험 테마 2종(`theme-apple`·`theme-meta`)은 `data-theme` 스코프 안에서만 덮어쓰고 기본값은 이 문서다. 롤백은 `styles.css`의 `@import` 한 줄 삭제.

## 4. 소유·변경 절차

- 토큰 값의 결정 주체는 **신현경**. 변경은 이 문서를 `v2`로 올리고(원본 보존) 그 뒤 `styles.css`를 맞춘다. 코드가 먼저 바뀌지 않는다.
- 이 문서의 표와 `styles.css` `@theme`가 어긋나면 **문서가 정본**이다.

v2 결정과 `frontend/src/styles.css` 현재 값의 차이. **프론트 담당(강병구)이 반영한다.**
**토큰만 지우면 조용히 깨지는 자리가 있다** — 아래 "함께 고칠 곳"을 같이 봐야 한다.
