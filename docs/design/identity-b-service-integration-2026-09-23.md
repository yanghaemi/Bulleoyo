# Identity B 운영 연결 및 MR 검증 기록

## 승인 범위

- 최초 중간 통합 요청 이후 사용자가 “연결까지 전부 진행해서 mr 올리자”로 운영 연결을 승인했다.
- 운영 홈 `/`과 공통 상단/하단 내비게이션에 Identity B를 연결한다. 새로운 화면 재설계가 아니다.
- 최초 운영 연결 실행의 공유 범위는 `develop` 대상 MR 생성까지였다. 당시 develop 병합·배포·자동 병합은 수행하지 않는 범위로 진행했다.
- develop 병합은 저장소 Jenkinsfile 기준 자동 개발 서버 배포를 실행한다. master 배포에는 별도 승인이 있다.

### 후속 승인: MR !185 병합

- 사용자가 “문제 없으면 merge 하자”로 MR !185의 `develop` 병합을 승인했다. 검토상 문제가 없음을 확인한 뒤 병합하고, 이에 따라 실행되는 자동 개발 서버 배포 결과까지 확인하는 범위다.
- 이 절은 승인 범위를 기록한다. 병합 성공·배포 성공을 확인한 결과는 별도로 남긴다.

## 변경과 보존

- A/B 랩, 타입·내비게이션 시편, 기존 후속 마감은 체크포인트 `3732c74`에 보존했다.
- `IdentityStage`와 SVG·스타일·폰트 로딩을 재사용 가능한 위치로 옮겼다. 운영 홈은 랩 페이지를 import하지 않는다.
- 현재 Pretendard 적용 범위는 Identity B 홈과 공통 헤더다. 다른 화면 전체의 서체를 바꾼 것은 아니다.
- `StageGalleryStage`·`EditorialLineupStage`는 과거 비교 실험으로 보존한다. 현재 운영 홈은 `IdentityStage`를 사용한다.
- `/performances`의 기존 공개 조회·날짜 필터·가격 변환을 유지한다. 추천 공연과 섹션에 같은 검색어를 적용한다.
- 포스터/목록 전환은 같은 공연 목록과 선택 ID를 유지하며 실제 상세 경로로 연결된다.
- 단일 공연일 때 artwork 모드의 복제 포스터와 이동 화살표만 숨긴다. 캐러셀 standard 기본 옵션은 보존한다.
- 프로필에 마이페이지·내 티켓·지갑·스튜디오·설정·언어·테마·로그아웃을 묶었다. 스튜디오 아래에 공연 만들기·공연 관리를 두고 공시 링크도 유지한다.
- 비회원 로그인은 모바일에서도 한 번에 접근한다. 메뉴의 스튜디오 링크는 기존 라우트의 인증·권한 검사를 사용한다.
- 로그아웃은 기존 useLogout 및 wallet adapter disconnect 흐름을 사용한다. 패널 재개방 중에도 중복 요청을 차단한다.
- 모바일 주요 메뉴는 공연 / 내 티켓 / 지갑 / MY이다.
- 승인된 내비게이션 명칭·프로필 메뉴 구성은 화면설계 v7 §1.2·§2·§5.17·§5.18에 반영한다. `지갑 / Wallet`은 진입 라벨이며 A-13 화면 제목과 잔액 패널의 `잔액 / Balance`, 잔액·결제·정산의 의미는 유지한다.
- 인증·권한·API 계약·예매·결제·지갑·정산의 구현과 상태 전이는 변경하지 않았다.
- 실제 API 포스터가 없으면 기존 브랜드 placeholder를 표시한다. 검토용 아티스트 포스터나 더미 회원 정보는 운영에 넣지 않는다.

## 이번 실행에서 확인한 결과

- 체크포인트: lint, typecheck, test(161 files / 1210 tests), build, diff check 통과.
- 운영 연결 회귀: 162 files / 1215 tests 통과. lint와 typecheck, production build 통과.
- 테스트는 이 실행에서 새로 수행했다. 이전 ZIP의 통과 기록을 재사용하지 않았다.
- 오류를 재현한 뒤 검증: 프로필 패널 재개방 중 logout 중복, 단일 공연 복제, 검색 필터 불일치, 운영 포스터/목록 선택 유지.
- 별도 읽기 전용 코드 리뷰: 모달보다 높은 헤더 stacking과 logout 중복 방지 수명 지적을 수정했고 재검토에서 Critical/Important 없음.
- 로컬 프론트가 운영 API의 공개 공연 목록을 조회하는 방식으로 실제 홈을 확인했다. 운영 DB 쓰기는 하지 않았다.
- 1440px 홈, 390px 홈/목록/설정 메뉴, 모바일 검색에서 실제 `/performances?keyword=…` 이동을 확인했다.
- 가로 넘침 검사와 CTA 상세 경로를 DOM으로 확인했다. 모바일 목록의 시각적으로 숨긴 제목은 접근성 트리에 유지된다.
- 기존 빌드의 큰 chunk 경고, 일부 의존성 annotation/browser externalization 경고 및 테스트 act 경고는 남아 있다.

## 후속 검증 및 제한

- 최신 develop과의 로컬 통합 결과를 별도로 검사한 뒤 MR을 생성한다. 통합 결과 커밋·검사 결과는 MR 본문에 남긴다.
- 실제 계정 로그인·실물 지갑 SDK 로그아웃·예매·결제·정산 거래는 실행하지 않는다. 해당 기능은 회귀 테스트와 기존 구현 보존으로 검사한다.
- 실기기 터치, Safari/Android 전 기종, OS 수준 200% 확대·모션 감소 설정은 이번 실행에서 검증하지 않았다.
- ZIP·PNG·GIF·로그·AGENTS.md 등 기존 미커밋 자료는 커밋에서 제외하고 원래 worktree에 남긴다.
